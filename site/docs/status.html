Production readiness

Honest snapshot before you use it.

Local / single-tenant preview: usable. B2B production is not. Tenancy exists in SQL. The product around it does not.

B2B

You can embed Efelant in a host that already has organizations by mapping org_id → tenant_id. The landing demo can pick a host and a tenant. You cannot ship “Efelant for Teams” yet: no Flutter switcher, invites, SSO, or per-tenant usernames.

Function API + RLS

Messenger

Trial-ready. Not a finished cryptosystem.

REST / gRPC

SQL handlers + BGWorkers. Connect JSON, not HTTP/2 framing.

Scale

Hundreds of devices, not millions. Connection-per-device.
