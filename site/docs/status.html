Production readiness

Honest snapshot before you use it.

Local / single-tenant preview: usable. B2B production is not. Tenancy exists in SQL. The product around it does not.

Scope

B2B

You can embed Efelant in a host that already has organizations by mapping org_id → tenant_id. The Flutter app can set the Efelant host. You cannot ship “Efelant for Teams” yet: no tenant switcher, invites, SSO, or per-tenant usernames. Gateway, keys, and E2EE status: security.

What is solid

Function API + RLS

Ready for a guarded company deploy.

Messenger

Trial-ready. Not a finished cryptosystem.

REST / gRPC

SQL handlers + BGWorkers. Connect JSON, not HTTP/2 framing.

Scale

Hundreds of devices, not millions. Connection-per-device.
