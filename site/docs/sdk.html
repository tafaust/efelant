SDKs

Hosts embed Efelant through packages. Core stays in PostgreSQL.

There is no Storybook. The visual catalog for tokens and component chrome is Styles. How to attach a conversation to a domain object: Embedding.

TypeScript

import { EfelantClient, createGatewayTransport } from "@efelant/client";

const client = new EfelantClient({
  transport: createGatewayTransport("/ws"),
});
await client.resume(token);

Browsers cannot speak the PostgreSQL wire protocol. Use createGatewayTransport. createMemoryTransport() is the same function names in memory. createMemoryHub() is one store, many connections. The landing-page demo is an in-memory Alice and Bob pair. The Flutter app sets the live host in settings.

Web components

Stencil UI is not pixel-shared with Flutter. Shared contracts are event names, models, and generated tokens.

Flutter

The messenger in app/ depends on efelant_flutter. Host apps import the same widgets.

EfelantConversation(
  tenantId: tenantId,
  context: EfelantContext(
    type: 'access_request',
    externalId: accessRequestId,
  ),
)

Widgets: EfelantConversation, EfelantConversationList, EfelantContextFeed, EfelantComposer, EfelantStatusEvent, EfelantUnreadBadge. Theme: buildEfelantTheme(theme: EfelantThemeId.primary).
